6. How to Interpret Results

  • Page Hit: The requested page is already in memory.
  • Page Fault: The requested page is not in memory.
  • FIFO: Replaces the page that entered memory first.
  • LRU: Replaces the page that was used least recently.
  • MRU: Replaces the page that was used most recently.
  • Hit Ratio: Hits divided by total requests, multiplied by 100.
  • Fault Ratio: Faults divided by total requests, multiplied by 100.
Educational simulator. This project models page replacement; it does not change your computer's actual memory management.
